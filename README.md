# MQJ MANHWA 4.2

نسخة GitHub Pages + GitHub Actions من MQJ MANHWA، مع مزامنة أكثر ثباتًا للكتالوج.

## ما تم إصلاحه في 4.2
- إصلاح أخطاء الـ regex التي كانت تمنع اكتشاف الفصول والروابط.
- دعم صفحة قائمة المانغا في Olympus (`/series`) مع التصفح بالصفحات.
- دعم صفحات قائمة MeshManga العامة ومحاولة اكتشاف الروابط من الـ sitemap عندما يكون متاحًا.
- دعم صور الفصل من `src` و`data-src` و`data-original` و`data-lazy-src` و`srcset` وبعض JSON-LD العام.
- تجاهل الفصول التي تظهر بوضوح كمدفوعة/مميزة بدل محاولة تجاوزها.
- إضافة `sync_status.json` لمعرفة عدد الأعمال التي اكتُشفت وأي أخطاء.
- إذا فشلت المزامنة ولم تُكتشف أي أعمال، لا يتم استبدال كتالوج سابق يعمل بكتالوج فارغ.
- استبعاد مصدر HentaiSlayer من المشروع.

## مهم
استخدم المشروع فقط مع المحتوى والمصادر التي لديك تصريح قانوني بفهرستها وإعادة عرضها. السكربت لا يتجاوز تسجيل الدخول أو CAPTCHA أو الحماية أو DRM أو الفصول المدفوعة.

## تشغيل GitHub Pages
1. ارفع ملفات هذا المشروع إلى المستودع.
2. اذهب إلى Settings → Pages.
3. اختر GitHub Actions كمصدر النشر إذا لم يكن مضبوطًا.
4. افتح Actions → `MQJ Manhwa Sync` واضغط `Run workflow`.
5. بعد نجاح العملية، افتح الموقع وانتظر تحديث Pages إذا لزم.

## حدود المزامنة
القيم الافتراضية موجودة داخل `scripts/sync.py` ويمكن تغييرها عبر متغيرات البيئة في Action:
- `MQJ_MAX_LIST_PAGES` = 130
- `MQJ_MAX_SERIES` = 1500
- `MQJ_MAX_CHAPTERS` = 200 لكل عمل

إذا كان المستودع بطيئًا، خفّض هذه القيم. وإذا كان تصريحك يسمح بمحتوى أكبر، يمكن رفعها لاحقًا.

## القارئ
`app.js` يقرأ `catalog.json` ويعرض الأعمال والفصول والصفحات داخل واجهة MQJ. الصور لا تُنسخ إلى GitHub تلقائيًا؛ يتم حفظ روابط الصور العامة فقط. إذا كان لديك تصريح بإعادة استضافة الصور، يمكن إضافة تخزين R2/S3 لاحقًا.
