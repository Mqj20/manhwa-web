# MQJ MANHWA 3.0
منصة عربية لعرض كتالوج المانهوا وقراءة الفصول داخل موقع MQJ.

## التشغيل
ارفع الملفات إلى GitHub Pages ثم افتح الموقع.

## إضافة مانhwa
عدّل `data/catalog.json`. كل عمل يمكن أن يحتوي على:
- id
- title
- description
- genres
- updated
- chapters: [{id, number}]

## إضافة فصل
أنشئ `data/chapters/<chapter-id>.json` بالشكل:
{"pages":["رابط-صورة-1","رابط-صورة-2"]}

استخدم فقط صوراً/ترجمات لديك الحق في عرضها أو إعادة نشرها.

## قسم البالغين
أضفت بوابة منفصلة تتطلب تسجيل دخول محلي وتأكيد 18+. هذا ليس نظام حماية حقيقي على GitHub Pages؛ للحماية الفعلية نربطه لاحقاً بـ Firebase Auth أو Supabase Auth.
