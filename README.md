# MQJ Manhwa Pro

نسخة حديثة من مشروع MQJ Manhwa تعتمد على جلب كتالوج المانهوا والفصول المتاحة ديناميكياً بدلاً من تخزين آلاف العناصر داخل `manhwa.json`.

## المزايا
- بحث مباشر.
- آلاف العناوين من API خارجي.
- تصنيفات وحالات.
- ترتيب حسب المتابعة/الأحدث/التقييم.
- تحميل تدريجي Infinite Scroll.
- صفحة تفاصيل لكل عنوان.
- جلب الفصول العربية المتاحة.
- قارئ صور للفصل.
- مكتبة محلية للمستخدم.
- متجاوب مع الهاتف والكمبيوتر والشاشات الكبيرة.

## النشر
ضع الملفات في مستودع GitHub Pages ثم فعّل Pages من Settings > Pages.
لا تحتاج إلى Python أو Node على GitHub Pages لأن الموقع النهائي static.

## ملاحظة
المشروع لا ينسخ مكتبة مانهاوا كاملة إلى GitHub؛ بل يجلب البيانات عند الحاجة. تأكد من احترام شروط استخدام مصدر البيانات وحقوق نشر كل ترجمة/عمل قبل إتاحته للمستخدمين.
